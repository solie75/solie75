#### About
Motion Matching으로 자연스러운 로코모션을 구현하고, Motion Warping을
활용한 정밀한 장애물 극복(Vault/Climb) 시스템을 C++ 레벨에서 설계·
디버깅하며 개발 중인 프로젝트입니다.

#### Tech Stack
`UE5.7 (C++)` `Motion Matching` `Motion Warping` `Pose Search`
